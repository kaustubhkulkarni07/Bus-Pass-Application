### BUS_PASS_SYSTEM(FOR MY COLLEGE)

E-Bus Pass is a modern, cross-platform mobile application built with Flutter and Firebase. It simplifies the process of applying for, renewing, and managing bus passes, replacing traditional paper-based systems with a seamless, interactive digital experience.

​## ✨Key Features

​User Authentication: Secure login and sign-up using Firebase Auth (Email/Password & Google Sign-In).
​Interactive UI: Smooth transitions, custom animations, and a clean, user-friendly interface.
​Digital Application: Multi-step form for applying for new passes with real-time validation.
​QR Code Pass: Generate unique QR codes for contactless ticket verification.
​Real-time Updates: Push notifications for application status and renewal reminders via Cloud Messaging.
​Secure Storage: Profile pictures and document uploads handled via Firebase Storage.
​
